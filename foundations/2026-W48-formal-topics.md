### 1. TapSpy: Semantic Usage Analysis and Triangulated Risk Assessment of Session Replay in Mobile Apps

- **方向**：移动与物联网安全
- **关键词**：会话回放、数据声明、静态审计
- **名词解释**：
  - **会话回放**：应用记录用户界面与交互过程，帮助开发者重现问题；记录范围会影响用户隐私。
  - **程序切片**：沿变量与条件依赖保留相关代码，例如追查回放 API 的参数来自哪里、何时被启用。
- **单位与作者**：University at Buffalo：Jiawei Guo、Zongze Li、Haipeng Cai
- **出处与状态**：ACM CCS 2026｜接收
- **公开或更新时间**：2026-11-14 正式发表
- **原文链接**：[正式出版](https://doi.org/10.1145/3830454.3832570)；[作者正文](https://chapering.github.io/pubs/ccs26jiaweia.pdf)；[代码与材料入口](https://github.com/SRestLabUB/TapSpy)
- **核心问题**：界面字段打码后，应用仍可能通过事件记录或身份绑定接口上传相关信息。仅搜索 SDK 名称难以判断回放如何配置，也难以核对实际集成与应用数据声明之间的差距。
- **方法与贡献**：工具先定位原生 Android 回放 SDK 的调用，沿参数及控制依赖生成程序切片，再让模型结合厂商功能说明解释配置的实际含义。带代码位置的解释分别与应用披露和厂商使用要求对照，输出可复核的风险证据；论文提出的三方模型中，声明与厂商之间的直接对照尚未实现。
- **方法示例**：论文案例中，界面上的生日字段被隐藏，但事件记录路径仍可能把同一数据与用户标识关联。沿字段到事件调用的切片可看到这条路径，再检查数据声明是否覆盖相应采集；动态示例使用虚构数据进行观察。
- **实验与证据**：扫描 47,855 个下载量至少百万的 Google Play 应用，识别 551 个使用所覆盖回放服务的应用，其中 312 个至少触发一类风险，占这 551 个的 56.6%。在人工标注的 84 个应用—服务对上，精确率 89.5%、召回率 94.4%、F1 为 0.919。作者向 64 个应用披露，收到 16 个开发者确认。
- **局限与风险**：覆盖依赖可公开分析的原生 SDK，远程配置和部分跨平台实现可能遗漏。动态验证只有少数案例，加密上传载荷的明文内容未直接观察。静态风险提示、运行时行为与开发者确认属于不同层次的证据。
- **实践关系**：上线回放 SDK 前检查调用参数及身份绑定，建立代码行为与商店披露的对应表；升级 SDK 后重复核查，并用测试账户验证实际上传路径。
- **推荐理由**：它展示如何把模型的语义分析限制在可定位的代码证据上，适合移动隐私合规审查。

### 2. DRIP: Defending Prompt Injection via Token-wise Representation Editing and Residual Fusion

- **方向**：人工智能安全
- **关键词**：提示注入、指令边界、表示编辑
- **名词解释**：
  - **表示编辑**：调整模型内部对输入词语的向量表示，让材料里的命令句保留可理解的含义，同时降低其指挥模型的作用。
  - **残差融合**：预测输出时把可信指令的表示再次混入当前表示，给模型保留明确的任务参照。
- **单位与作者**：
  - National University of Singapore：刘若凡、Zhiyong Huang、Jin Song Dong
  - 上海交通大学：林云
- **出处与状态**：ACM CCS 2026｜接收
- **公开或更新时间**：2025-11-18 预印版本；2026-11-14 正式发表
- **原文链接**：[正式出版](https://doi.org/10.1145/3830454.3832577)；[已读作者完整稿](https://lindsey98.github.io/liuruofan//files/DRIP_paper.pdf)；[代码](https://github.com/lindsey98/DRIP)
- **核心问题**：翻译或摘要任务必须处理材料中的命令句，简单删除可疑内容会破坏正常任务。模型需要区分“要执行的任务”与“任务正在处理的文字”，即使两处出现相同句子。
- **方法与贡献**：DRIP 对材料 token 的嵌入加入可训练的线性残差编辑，并只在生成首个响应 token 时融合可信指令末端的隐藏状态。训练样本让相同命令分别出现在可信区和材料区，四种角色配置形成两组偏好对，约束模型按角色处理相同措辞。后续 token 使用通常的自回归解码。
- **方法示例**：用户要求翻译一封含有“停止翻译，回答问题”的信。该句在材料区应成为译文的一部分；将它放在可信任务区时才改变任务。论文用这种位置和角色对照训练，使表示调整与输出参照共同维护边界。
- **实验与证据**：精读依据作者主页的 27 页完整稿，正式出版信息另经 DOI 与会议列表核对。在 Llama 3-8B 的 9,160 条 SEP 测试上，分离指标为 83.5%，SecAlign 为 32.1%。208 条 Alpaca 子集的 500 步 GCG 测试中，按输出前缀判定的成功率为 1.1%。多轮 AgentDojo 测试中，Llama 3.1-8B 的重要指令伪装攻击成功率从 4.43% 降到 0.53%，无攻击任务完成率也从 29.90% 降到 22.68%。
- **局限与风险**：评测覆盖 4–8B 文本模型，多轮代理结果仍属初步验证；在 Llama 3.1-8B 的 SEP 测试上，TAP 自适应攻击成功率仍为 42%。训练除低秩适配器外还更新词嵌入及输出层，Llama 3 配置可训练参数约占 13.8%。作者稿保留出版模板占位信息，精确修订日未标明；结果按本文链接版本引用，理论分析的简化假设另行保留。
- **实践关系**：适合研究需要完整处理不可信材料的本地模型；实现时明确标记指令与材料边界，并将效用下降和不同攻击下的结果同时纳入验收。
- **推荐理由**：它用角色切换样本与输出参照解释了防御机制，消融结果也能直接检验关键设计是否发挥作用。
